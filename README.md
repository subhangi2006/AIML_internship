# Introduction to AI & Python

Beginner-friendly internship repository covering the five learning objectives.

## Contents
- `learning-notes/AI_and_Python_Learning_Notes.md` — complete study notes.
- `learning-notes/Progress_Log.md` — learning diary template.
- `python-practice/` — six beginner Python programs.

## Install Python
1. Download Python 3 from https://www.python.org/downloads/
2. On Windows, select **Add Python to PATH** during installation.
3. Open Command Prompt / Terminal and check `python --version` (or `py --version` on Windows).

## Run programs
From this folder, run for example:
```bash
python python-practice/01_variables_datatypes.py
```
Run the other `.py` files in the same way.

## Learning workflow
Read the notes, run each program, try different inputs, modify the code, and record your progress in `learning-notes/Progress_Log.md`.
